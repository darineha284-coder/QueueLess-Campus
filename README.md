QueueLess Campus – Smart Canteen Pre-Order & Queue Management System

Tagline: Skip the queue. Enjoy your break.

Project Description

QueueLess Campus is a Java-based desktop application designed to simplify food ordering in college canteens. Students can view available food items, add items to their cart, and place orders with a pickup time. Administrators can add food items, view orders, and update order statuses.

Objectives
Reduce waiting time at the college canteen.
Make food ordering easier for students.
Maintain order details in a database.
Help administrators manage food items and orders.
Technologies Used
Programming Language: Java
Frontend: Java Swing
Database: MySQL
Database Connectivity: JDBC and MySQL Connector/J
IDE: IntelliJ IDEA
Key Features
View available food items and prices.
Add food items to a cart.
Calculate the total order amount.
Place food orders and receive a token number.
Add food items through the admin dashboard.
View customer orders.
Update order statuses: PLACED, PREPARING, READY, and COMPLETED.

Database Setup

The application uses a MySQL database named queueless_campus.

Create the database and configure the required tables before running the application. Update the database connection settings on your computer with your own MySQL credentials.

Security note: Never publish your actual database password in this repository.
